# 生成画像の選定（2026-10-28）

モデル: bytedance-seed/seedream-4.5（OpenRouter）。プロンプトは `scripts/gen_images.py`。
候補は各5枚を `assets_ai/cand/` に保存（容量が大きいため git 管理外・ローカルに温存）。

| 用途 | 採用 | 理由 |
|---|---|---|
| 通常表示のパネル | panel_3 | 四辺がまっすぐで横長、中央が均一な暗いガラスで数字が映える。装飾が四隅寄りなので9スライスで伸ばしても崩れない |
| ミニ表示のパネル | mini_4 | 正面がフラットで面取りの角がきれい。窓が広く均一 |
| アイコン | icon_1 | 線が太く、32px でもストップウォッチと分かる |

不採用の理由: panel_1 は辺の中ほどにブラケットがあり、伸ばすと歪む。panel_2/4 は縦横比が合わない。
panel_5 は下に影が落ちている。mini_1/5 は窓の中に棒状の装飾がある。

切り抜き: `scripts/cutout.py`（panel と mini は面取り長方形として外形を測る。mini は本体の下の台座と床の影を切り捨てる。icon は四隅の色との差で判定）→ `scripts/make_icon.py`。
